# MAX CARD FINANCE PRO

ارفع index.html و style.css و app.js و sw.js إلى جذر مستودع GitHub. من Settings > Pages اختر Deploy from a branch ثم main و /(root). افتح الرابط الناتج. حدد فترة الجرد قبل تسجيل العمليات. رأس المال الابتدائي 150 دولار ويمكن تعديله قبل أول حركة. سجّل الأرصدة الفعلية قبل إغلاق الفترة. احتفظ بنسخة JSON دورياً من الإعدادات.

البيانات محلية في localStorage وليست مشفرة أو متزامنة. رمز PIN قفل واجهة فقط. يعمل التخزين دون اتصال بعد تحميل الموقع وتثبيت ذاكرة الخدمة على HTTPS. تصدير Excel بصيغة CSV، وPDF عبر نافذة الطباعة. لا يوجد شعار رسمي مرفق. لا تستخدمه كسجل وحيد قبل اختبار دورة كاملة ببيانات اختبار ونسخ احتياطية. تم فحص بناء JavaScript بواسطة Node، ولم يتم اختبار جميع المتصفحات أو الجهاز الفعلي.
